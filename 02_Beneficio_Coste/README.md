# 02. Relación Beneficio/Costo

## Situación Actual
Actualmente el proceso requiere:

- Descarga de archivos.
- Validaciones manuales.
- Cruces en Excel.
- Verificación de diferencias.

Estas actividades generan:

- Consumo de tiempo.
- Dependencia de revisiones manuales.
- Riesgo de errores.

---

## Beneficios Esperados

### Operativos
- Automatización de las actividades de preparación, integración, cálculo y generación del reporte de diferencias.
- Reducción del tiempo de análisis.
- Menor intervención manual.

### Financieros
- Detección oportuna de diferencias.
- Mayor control sobre el capital de cartera.
- Menor riesgo de errores en reportes financieros.

### Estratégicos
- Calidad de datos.
- Información confiable.
- Soporte para auditorías y controles internos.
