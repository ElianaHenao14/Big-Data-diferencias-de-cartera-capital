# 5. Modelo de Ciencia de Datos (8%)

## Estadística Descriptiva

### Indicadores:

**KPI 1**
Total NIT procesados.

**KPI 2**
Cantidad de diferencias detectadas.

**KPI 3**
Valor total de diferencias.

**KPI 4**
Promedio de diferencia por cliente.

**KPI 5**
Porcentaje de registros conciliados.

**Fórmula:** 
(Registros sin diferencia / Total registros) * 100
